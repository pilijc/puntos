# Puntos Mobile

Expo/React Native app for the Puntos rewards platform.

## Documentation Overview

To keep this guide concise and avoid mixing runbook details with sensitive environment instructions, our documentation is split into dedicated guides. Please refer to the following resources:

1. **[Operational Runbook](./docs/operational-runbook.md)**
   Covers running the app with **Docker** (Metro + Node), Android environment setup (ADB/Emulator), and daily development commands.

2. **[Security Notes](./docs/security-notes.md)**
   Important notes regarding Docker network constraints, host machine requirements, and our policy on hardcoded credentials.

3. **[Sample Data Policy](./docs/sample-data-policy.md)**
   Information regarding our local Supabase seed script and how to generate test accounts for different roles (Super Admin, Store Manager, Front-desk, User).
